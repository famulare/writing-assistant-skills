# Minimal Edit

Use when existing prose is present.

If available, read `../../references/writing-skill-common.md` for risk tiers
and the output envelope.

If `../../voice/voice-card.md` exists, read it when the edit involves Mike's
voice, register, compression, terminology, or translation between rough and
formal prose. Use only the relevant register or voice-card entries; do not paste
or summarize the whole card unless asked.

## Mode

EDIT.

## Procedure

1. Identify the bounded unit.
2. Leave finished text unchanged.
3. Apply low-risk fixes directly.
4. Show medium-risk edits visibly with short rationales.
5. Propose high-risk edits as alternatives. Ask before applying when the task
   does not already authorize them.
6. Preserve meaningful compression and unusual distinctions.
7. Reserve "must" / "essential" framing for fidelity-preserving fixes. An *added*
   citation, claim, or example is propose-tier (medium- or high-risk), never
   "must-fold" — recommending it as required oversteps the author's role.

## Revision priority

1. preserve meaning
2. preserve voice
3. preserve order
4. fix grammar
5. improve clarity
6. improve flow
7. polish, restrained and last

## Output

Choose the lightest reviewable surface that fits the task:

- annotated original/proposed snippets
- markdown diff
- revised bounded unit plus change log
- direct file edit plus summary, only when Mike explicitly requests the file edit

Always list:

- substantive changes
- new claims
- certainty shifts
- terminology changes
- high-risk edits not applied

## Verification

- Unchanged text remains unchanged.
- Edits are no larger than needed.
- Claim strength is stable.
- Terminology is stable unless explicitly changed.
- The result does not sound like generic AI prose.
