# /voice-costume-audit

Audit a finished whole artifact for an unsupported document-wide rhetorical
persona:

`$ARGUMENTS`

Read these files if available:

- `references/writing-skill-common.md`
- `skills/voice-costume-audit/SKILL.md`
- `references/independent-review-prompts.md`

Run the mandatory independent blind/reveal protocol. The fresh reviewer first
receives only the artifact and artifact type and freezes a persona profile. Only
then reveal the raw author language/frankendraft, artifact contract, relevant
voice evidence, and explicit author decisions. Do not reveal drafting rationale,
prior audit conclusions, or the suspected failure. Classify the inferred persona
as source-earned, contract-required, author-approved, unsupported costume, or
underdetermined. Treat costume as a diagnostic finding, not an automatic defect:
return the keep/modify/remove decision to the human. Propose bounded options;
never silently rewrite the whole artifact. In an autonomous demo, label any
demo-agent choice as simulated and not author-approved.
