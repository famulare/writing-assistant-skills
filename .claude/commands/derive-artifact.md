# /derive-artifact

(v0 / PROVISIONAL — evidence is thin; expect a near-term revision.)

Produce a downstream artifact from a finished dossier for:

`$ARGUMENTS`

Read these files if available:

- `references/writing-skill-common.md`
- `skills/derive-artifact/SKILL.md`

Take a *finished* dossier and re-render its spine into a new form (executive
summary / reader memo / cover note) for a different reader — do not draft the
source document itself. Extract the spine (`extract-argument`), build an outline
for the new form (`build-outline`), compose under heavy voice control since the
hole-fill path dominates (`compose-section`), then audit (`final-audit-pass`).
Re-assert the source's hardened ledger claim strengths — do not loosen, round, or
drop caveats for brevity. Mark any new framing, emphasis, or reordering as
authored (`[CLAIM RISK: …]` / `[SCOPE RISK: …]`). Invent no unsourced claim; mark
missing support `[EVIDENCE NEEDED: …]` rather than filling it. To compose a
section of the source document itself, use `/compose-section`. Do not use this
command for a parallel register rendering of the same source: both renderings
must branch from the shared frankendraft. The dossier/ledger may control claims
without becoming voice authority.
