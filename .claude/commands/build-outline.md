# /build-outline

Build (or re-architect) the outline for:

`$ARGUMENTS`

Read these files if available:

- `references/writing-skill-common.md`
- `skills/build-outline/SKILL.md`

Two stages. **Stage 1 (skeleton):** section purpose, claim, evidence, citation
needs, transition logic, known gaps, and risk flags — make reordering visible,
do not hide structural changes inside a clean outline. **Stage 2 (contract):**
render the ordered outline as per-section contracts (Purpose / Must-claim /
Must-not-claim / Source-hooks / beats) for `frankendraft` / `compose-section`.

If an outline already exists and the framing changed, re-architect it: evaluate
current beats (keep / reorder / orphan / add-new), surface high-risk structural
moves for the author to decide, then refill the contract. Produce the contract;
do not draft prose.
