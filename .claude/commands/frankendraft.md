# /frankendraft

Assemble a pure-verbatim first-pass draft from only the author's own words for:

`$ARGUMENTS`

Read these files if available:

- `references/writing-skill-common.md`
- `voice/voice-card.md`
- `skills/frankendraft/SKILL.md`

Pull the author's verbatim passages and arrange them to the outline/contract;
invent nothing and leave register and grammar raw — these are the author's words,
not cleaned prose. Mark a hole (`….[note]`) wherever no verbatim exists; the hole
map is the downstream voice-risk surface. Apply only the marked, minimal
corrections in the skill. Then run the required independent verbatim-fidelity audit
in a fresh context (subagent or separate reviewer model) and restore any
over-correction to exact source.

Run this before `/compose-section` when the author wants the draft to start
from their own language.
